# V.O.I.C.E. - Virtual Outlet for Institutional Complaint Engagement

V.O.I.C.E. is a modern, high-performance institutional complaint and feedback management system built with Laravel, MySQL (TiDB Cloud), and Real-time WebSockets.

## Deployment Status
This project is configured for deployment on **Hugging Face Spaces** using a single-container Docker setup.

## Technical Stack
- **Framework:** Laravel 11
- **Real-time:** Laravel Reverb
- **Database:** TiDB Cloud (MySQL Compatible)
- **Runtime:** Docker + Nginx + PHP-FPM 8.3
- **Port:** 7860 (Hugging Face Default)
